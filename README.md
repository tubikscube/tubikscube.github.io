# Tuğba Altın — personal website

Source for <https://tubikscube.github.io/>, my academic website.

It is a small static site: plain HTML, CSS and a little JavaScript, no build step. Pushing to `main` publishes it through GitHub Pages. I built it with the help of AI tools, using open-source typefaces (Cormorant Garamond and DM Sans, SIL Open Font License).

You are welcome to look at how it is put together. The photographs, texts and other personal material are mine, so please ask before reusing them.
